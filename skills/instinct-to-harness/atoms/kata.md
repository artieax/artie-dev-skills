# kata — minimal copy-paste recipe

Render an instinct as a short, copy-pasteable pattern with no branching. Like a katà in martial arts — one move, learn the form.

## When this fits

- Source mode is `success-pattern` — what worked, no exceptions
- `polarity: good`
- The instinct is *one* technique, not a decision

## Output shape

```markdown
# <title>

```<lang>
<minimal working snippet>
```

That's it. <one sentence on when to use it>.
```

## Anti-pattern

Don't pad a kata with "Why" / "Context" — if the user needs context they're using the wrong instinct. Pick `story-arc` instead.
